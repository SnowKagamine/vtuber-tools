🔍 歌曲搜尋的三個視角

搜尋頁的上方有三個分頁切換,同一組搜尋條件可以用不同方式瀏覽:

  • 📋 歌曲清單:所有唱過的歌,扁平列表,最直觀。
  • 📅 依直播分組:按場次分組,想看「某場歌回唱了什麼」就用這個。
  • 🕒 最近播放:你瀏覽過的歷史(存在你瀏覽器,不會上傳)。
💡 右上有「包含 NG / 特殊版本」勾選框 — 預設**不列** NG 片段跟改詞版本,想看就勾起來。

📂 我的歌單

你可以建立無限數量的自訂歌單,把喜歡的歌分類收藏:

  • 建立新歌單:在歌單側邊欄的「+ 新增歌單」按鈕
  • 加歌到歌單:歌卡的 ⋮ → 收藏至 [歌單名]
  • ⭐ 我的最愛:特殊預設歌單,所有收藏的歌自動放這
  • 排序:歌單內可以拖曳歌曲改順序
  • 💾 匯出此歌單:備份單一歌單成 JSON 檔
  • 💾 匯出所有歌單:備份全部
  • 📥 匯入:自動智慧偵測,衝突名字自動加編號不會覆蓋
⚠️ 歌單**存在你瀏覽器**本機,換裝置或清快取會不見。重要歌單記得匯出備份!

❓ 常見問題

這網站是官方的嗎?

不是,這是**粉絲自製**的轉載整理網站,非春魚創意或安特羅迦官方所屬。

NG 跟特殊版本是什麼?

🎭 NG 是歌回中忘詞、唱錯、彩蛋的片段。🎤 特殊 主要是改詞版本或特別變奏。預設兩者都不列入正常統計與列表,想看要勾右上的「包含 NG / 特殊版本」。

我剪了精華片段怎麼投稿?

找到你剪的那首歌 → 點歌卡的 🎬 按鈕 → 選單底部「➕ 我想投稿剪輯精華」。表單會自動帶入歌曲資訊,你只要填作者名跟 YouTube 連結。審核通過後會顯示在對應歌曲的 🎬 選單中。

我的歌單在其他裝置看不到?

歌單**存在你的瀏覽器本機**(localStorage),不會自動同步到其他裝置。如果想在手機跟電腦都用,請用「💾 匯出此歌單」或「💾 匯出所有歌單」備份成 JSON 檔,再在另一個裝置匯入。

清快取 / 換瀏覽器會不會丟失歌單?

會。瀏覽器清除「網站資料」或「所有 cookie」會把歌單一併清掉。建議**定期匯出備份**。歌單本身是純文字 JSON 檔,存雲端或電腦都很小。

更新通知(鈴鐺紅點)怎麼關掉?

點鈴鐺開啟通知視窗,就會自動標記為已讀。只有真正有新通知時才會跳紅點。

右下彈出「網站已更新」怎麼辦?

代表網站有新版本功能或 bug 修補,建議按「🔄 立即重新整理」拿到最新版本。如果現在不方便,按「稍後」會先關掉,下次有更新版再提示。

發現 bug / 歌單資料錯誤怎麼辦?

頁尾有「📝 回饋表單」,歡迎回報!類別可選 bug 回報、內容錯誤、功能建議等。
